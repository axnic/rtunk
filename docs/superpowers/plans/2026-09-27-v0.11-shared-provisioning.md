# v0.11 Shared Provisioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close ROADMAP.md v0.11's two "provisioning" items — one shared implementation for variable substitution and runtime resolution (today duplicated between `pkg/trunk/engine` and `pkg/trunk/actions`), and actions provisioning through the same `download.Ref`/`download.Download` path everything else uses, instead of a bespoke direct install call. This is the second of five independent plans covering v0.11; the first (cache consolidation) already merged to `main`.

**Architecture:** `resolveRuntimeShimDir` exists twice, near-verbatim, in `pkg/trunk/engine/engine.go` and `pkg/trunk/actions/run.go` — both already import `pkg/trunk/download`, so the shared core moves there. `quoteOne`/`quoteAll` (shell-quoting for `${...}` substitution) are duplicated the same way and move alongside it. Separately, `pkg/trunk/actions/run.go`'s `resolvePackagesFileBinDir` installs an action's `packages_file` manifest by calling `download.InstallPackagesFile` directly — bypassing `download.Download`'s `Ref`-based dispatch, its per-install lock (`claimInstall`, from the merged cache-consolidation plan), and the usage registry (`RecordUsage`/`resolvedRefs`) that same plan added. This plan gives it a real `Ref.Category` ("action-packages") so it goes through the identical path tools/runtimes already do — which also closes a gap the cache-consolidation plan's final review flagged and deliberately parked: action-packages installs were invisible to `cache prune`.

**Tech Stack:** Go stdlib only.

**Spec:** [ROADMAP.md](../../../ROADMAP.md), "v0.11 — Cache, provisioning, and catalog fidelity", the two bullets: "One shared implementation for variable substitution and runtime resolution" and "Actions provision through the runtime path only."

## Global Constraints

- No Windows support — no Windows-specific branches.
- A cache-bookkeeping failure (recording usage, releasing a lock) must never fail a real check/fmt/run/actions invocation.
- `Touch` (mtime bump) must only run after a fetch has genuinely succeeded — never before, and never if the fetch is skipped because the item was already cached but the fetch would have failed had it been attempted. Preserve this ordering exactly; it is already correct in both existing duplicated implementations and must stay correct after unification.
- `engine.go`'s `resolveRuntimeShimDir` pre-checks `failed[...]` (a map `prefetch` already populated for this batch) before doing anything else, and reports progress through `emit`/`forwardInstall`'s existing Event-translation table. `actions/run.go`'s version does neither — it has no batch-level `failed` map and no progress-emission mechanism. The shared core this plan extracts must not force either caller to add machinery it doesn't have today.

## Review Focus

- A runtime already cached (shim exists on disk) must resolve with zero calls to `download.Download` in either caller, exactly as today — the shared core's cache-hit path must stay a pure `os.Stat` check.
- An action's `packages_file` manifest that resolves to a content hash already installed by a *different* action (two actions sharing one manifest) must still dedupe to one on-disk install, exactly as `resolvePackagesFileBinDir`'s doc comment already promises today — a regression here would double-install.
- Two actions with different `packages_file` manifests running concurrently (e.g. two `--hook` actions in one `pre-commit` run) must not race each other's install the way the pre-cache-consolidation tools/runtimes install path used to — since this plan routes action-packages through the *already-locked* `download.Download` path, this should now be structural, not something this plan adds new locking for; a test proving it is cheap insurance.
- `cache prune`, after this plan, must actually remove an action-packages install no live repository's registry references — the gap the previous plan's final review found and parked. A test belongs here, not deferred again.
- An action with no `packages_file` at all (the common case — most real catalog actions don't set one) must be completely unaffected: no new `Ref`, no new registry entry, no behavior change.

```go
// Package download's runtime_shim.go implements ROADMAP.md v0.11's "one shared implementation
// for variable substitution and runtime resolution": the runtime-shim-directory resolution logic
// pkg/trunk/engine and pkg/trunk/actions each used to duplicate near-verbatim.
package download

import (
	"fmt"
	"os"
	"path/filepath"

	"github.com/xunleii/rtunk/pkg/trunk/config"
)

// ResolveRuntimeShimDir resolves runtimeID's shim directory, fetching it first via Download if not
// already cached (a shim already on disk is treated as fully installed, matching every other
// cache-hit check in this package). onEvent, when non-nil, is called once per event a triggered
// fetch emits -- callers that report progress (pkg/trunk/engine) translate through their own
// mechanism; callers that don't (pkg/trunk/actions) pass nil. Touch only runs once every event has
// been consumed with none of them Failed, so a failed fetch never bumps the mtime a future `cache
// prune` reads.
func ResolveRuntimeShimDir(cfg config.Config, root, cacheDir, repoRoot, runtimeID string, onEvent func(Event)) (string, error) {
	rt, ok := cfg.Runtimes.Definitions[runtimeID]
	if !ok {
		return "", fmt.Errorf("download: parser runtime %q referenced but not found in resolved config", runtimeID)
	}
	if len(rt.Shims) == 0 {
		return "", fmt.Errorf("download: parser runtime %q has no shims declared", runtimeID)
	}
	version := ResolveVersion(cfg.Runtimes.Enabled, runtimeID, rt.KnownGoodVersion)
	shimPath := ShimPath(root, "runtimes", runtimeID, version, rt.Shims[0])
	if _, statErr := os.Stat(shimPath); statErr != nil {
		evs, err := Download(cfg, cacheDir, repoRoot, Ref{Category: "runtimes", ID: runtimeID, Version: version})
		if err != nil {
			return "", err
		}
		for ev := range evs {
			if onEvent != nil {
				onEvent(ev)
			}
			if ev.Phase == Failed {
				return "", ev.Err
			}
		}
	}
	Touch(root, "runtimes", runtimeID, version)
	return filepath.Dir(shimPath), nil
}
```

```go
func resolveRuntimeShimDir(cfg config.Config, root, cacheDir, repoRoot, runtimeID string, failed map[string]error, emit func(Event)) (string, error) {
	if err := failed["runtimes/"+runtimeID]; err != nil {
		return "", err // already attempted (and reported) by prefetch
	}
	started := false
	dir, err := download.ResolveRuntimeShimDir(cfg, root, cacheDir, repoRoot, runtimeID, func(ev download.Event) {
		item := ev.Ref.Category + "/" + ev.Ref.ID

			emit(Event{Phase: InstallStart, Item: item, BytesTotal: -1})

			emit(Event{Phase: InstallProgress, Item: item, Bytes: ev.Bytes, BytesTotal: ev.Total})

			if started {
				emit(Event{Phase: InstallDone, Item: item})
			}
		}
	})
	return dir, err
}
```

```go
// fetchActionPackagesRef installs ref.ID's (an action id) packages_file manifest, deduped by the
// manifest's own content hash so two actions sharing one manifest install once -- mirrors
// fetchToolRef's runtime+package branch, just keyed by content hash instead of a declared version.
func fetchActionPackagesRef(cfg config.Config, root, repoRoot string, ref Ref, events chan<- Event) {
	action, ok := cfg.Actions.Definitions[ref.ID]
	if !ok || action.PackagesFile == "" {
		events <- Event{Ref: ref, Phase: Failed, Err: fmt.Errorf("download: action %q has no packages_file", ref.ID)}
		return
	}
	rt, ok := cfg.Runtimes.Definitions[action.Runtime]
	if !ok {
		events <- Event{Ref: ref, Phase: Failed, Err: fmt.Errorf("download: action %q: no runtime %q", ref.ID, action.Runtime)}
		return
	}
	runtimeVersion := ResolveVersion(cfg.Runtimes.Enabled, action.Runtime, rt.KnownGoodVersion)
	runtimeInstallDir := InstallDir(root, "runtimes", action.Runtime, runtimeVersion)
	if !dirNonEmpty(runtimeInstallDir) {
		if err := fetchRuntimeRef(cfg, root, repoRoot, Ref{Category: "runtimes", ID: action.Runtime, Version: runtimeVersion}, events); err != nil {
			events <- Event{Ref: ref, Phase: Failed, Err: fmt.Errorf("download: action %q: runtime %q: %w", ref.ID, action.Runtime, err)}
			return
		}
	}

	data, err := os.ReadFile(action.PackagesFile)
	if err != nil {
		events <- Event{Ref: ref, Phase: Failed, Err: err}
		return
	}
	sum := sha256.Sum256(data)
	hash := hex.EncodeToString(sum[:])
	installDir := InstallDir(root, "action-packages", hash, "manifest")
	if dirNonEmpty(installDir) {
		events <- Event{Ref: ref, Phase: Cached}
		return
	}

	release, ok := claimInstall(ref, installDir, repoRoot, events)
	if !ok {
		return
	}
	defer release()
	events <- Event{Ref: ref, Phase: Started}
	if err := InstallPackagesFile(rt, runtimeInstallDir, installDir, action.PackagesFile); err != nil {
		events <- Event{Ref: ref, Phase: Failed, Err: err}
		return
	}
	events <- Event{Ref: ref, Phase: Done}
}
```

You will need `"crypto/sha256"`, `"encoding/hex"`, and `"os"` imported in `download.go` if not already present.
